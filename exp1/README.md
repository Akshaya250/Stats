# exp1

Description
- This folder contains an experiment script and a dataset (`diabetes.csv`). The script `exp1.py` runs a machine learning experiment using the diabetes dataset.

Files
- `diabetes.csv`: CSV dataset used by `exp1.py`.
- `exp1.py`: Experiment script (data loading, preprocessing, model training/evaluation).

Requirements
- Python 3.8+
- pandas, scikit-learn, numpy

Run
```bash
python exp1.py
```

Notes
- Inspect `exp1.py` to see exact preprocessing and model choices.
