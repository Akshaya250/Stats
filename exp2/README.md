# exp2

Description
- This folder contains an experiment script and a dataset (`diabetes.csv`). The script `exp2.py` runs a variation of the diabetes experiment (different preprocessing or model settings).

Files
- `diabetes.csv`: CSV dataset used by `exp2.py`.
- `exp2.py`: Experiment script (data loading, preprocessing, model training/evaluation).

Requirements
- Python 3.8+
- pandas, scikit-learn, numpy

Run
```bash
python exp2.py
```

Notes
- Check `exp2.py` for configuration differences from other experiments.
