# exp4

Description
- This folder contains an experiment script and a dataset (`diabetes.csv`). The script `exp4.py` runs an alternate experiment using the diabetes dataset.

Files
- `diabetes.csv`: CSV dataset used by `exp4.py`.
- `exp4.py`: Experiment script (data loading, preprocessing, model training/evaluation).

Requirements
- Python 3.8+
- pandas, scikit-learn, numpy

Run
```bash
python exp4.py
```

Notes
- Review `exp4.py` for the experiment's specific parameters.
