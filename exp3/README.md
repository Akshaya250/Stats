# exp3

Description
- This folder contains an experiment script and a dataset (`diabetes.csv`). The script `exp3.py` runs another experiment variant on the diabetes dataset.

Files
- `diabetes.csv`: CSV dataset used by `exp3.py`.
- `exp3.py`: Experiment script (data loading, preprocessing, model training/evaluation).

Requirements
- Python 3.8+
- pandas, scikit-learn, numpy

Run
```bash
python exp3.py
```

Notes
- Compare `exp3.py` with other `exp*.py` files to see changes.
